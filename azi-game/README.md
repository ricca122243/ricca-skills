# Ази Клуб

Казахская карточная игра «Ази» на виртуальные монеты. Один файл `index.html`, без сервера: открывается в браузере телефона, прогресс хранится в памяти браузера.

## Что внутри

- **Ази**: 27 карт (♠ ♥ ♣, от 6 до туза), по 3 карты, открытый козырь, «Шоха на трассе» (козырный туз → шестёрка козыря старшая). Карты приходят рубашкой вверх: пока не открыл — играешь в тёмную, ставки вдвое дешевле. Торговля: бросить / уравнять / поднять; повышение минимум ×2, сумма выбирается вертикальным ползунком до ва-банка. При ва-банке победитель забирает только то, что сам покрыл, лишнее возвращается. Ход: в масть → козырем → любой. 2 взятки из 3 забирают банк. Иначе «Ази»: банк остаётся, с одной взяткой — бесплатно, без взяток — за полбанка, сбросившие — за весь банк.
- **Столы**: Көктөбе 50, Шарын 500, Бәйтерек 5K, Медеу 50K, Хан Тәңірі 500K (анте). Список столов, создание стола на 2–6 игроков, боты с характером.
- **Ставочные программы**: турнир часа (топ‑30 получают призы), слот «Алтын» (5 линий, возврат ≈ 93%, ×2 за алмазы), колесо удачи раз в сутки, бонус каждые 3 часа, пакет батыра с таймером.
- **Валюты**: монеты — игровая валюта для ставок; алмазы — премиум (аватары, шапки, обмен на монеты).
- **Магазин**: монеты, алмазы, закидушки (помидоры, яйца, розы), шапки (калпак, тымақ, корона…), аватары (Батыр, Ханша, Бүркітші, Ақын, Апа).
- **Стол**: фразы, броски в игроков, уровни и XP, звук.

## Перед релизом

- Покупки за ₸ сейчас демо: нужно подключить App Store / Google Play (или Kaspi для веба).
- Игроки — боты. Для настоящего мультиплеера нужен сервер (комнаты, раздача и проверка ходов на сервере).
- Возраст 18+, монеты нельзя выводить — это оставить в тексте и в карточке магазина приложений.
