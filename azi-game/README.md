# Ази Клуб

Казахская карточная игра «Ази» на виртуальные фишки. Один файл `index.html`, без сервера: открывается в браузере телефона, прогресс хранится в памяти браузера.

## Экраны

- **Главная**: прогресс уровня («Подробнее»), блок «Главная» (Супер Турнир с таймером, Специальная скидка, Слоты для вас, Магазин), «Играть сейчас» — локации со ставкой и числом игроков, плавающая кнопка «Играть сейчас». В шапке: аватар с уровнем, баланс фишек и золота (ведёт в магазин), колокольчик (бонус каждые 3 часа, колесо удачи, события).
- **Локация** → список комнат «Комната #NNNN · N из 6 игроков», «+ Создать игру» → выбор числа игроков 2–6.
- **Стол**: игроки по кругу с уровнем, балансом и бейджами (Поднял / Уравнял / Пас / Раунд / Банк / Ва-банк), козырь и банк в центре, ставки фишками перед игроками, большие карты внизу. Нижняя панель: выход, фразы, история раздачи, звук. На вашем ходу — «Бросить / Уравнять / Поднять» и вертикальный ползунок до ва-банка.
- **Супер Турнир**: призовой фонд (фишки, золото), призы за места 1, 2–10, 11–30, кнопки «Правила / Играть / Лидеры».
- **Магазин**: Фишки, Золото, Предметы (закидушки, шапки), Аватары.
- **Специальная скидка**: полноэкранное предложение с таймером. **Слоты**: 3×3, 5 линий, таблица выплат, «Увеличить выигрыш на ×2».

## Правила

27 карт (♠ ♥ ♣, 6–Т), по 3 карты рубашкой вверх, открытый козырь, «Шоха на трассе». В тёмную ставки вдвое дешевле. Первый игрок открывает торг или бросает; повышение минимум ×2 до ва-банка. Ход в масть → козырем → любой. 2 взятки из 3 забирают банк; иначе «Ази» — переигровка (с одной взяткой бесплатно, без взяток за полбанка, сбросившие за весь банк). При ва-банке победитель забирает только покрытую часть.

## Перед релизом

- Покупки за ₸ сейчас демо — подключить App Store / Google Play (или Kaspi для веба).
- Игроки — боты. Для живого мультиплеера нужен сервер (комнаты, раздача и проверка ходов на сервере).
- Возраст 18+, фишки нельзя выводить — оставить в тексте и в карточке магазина приложений.
