# Истикама — игра дисциплины

Приложение (PWA) для iPhone и ноутбука: привычки по сферам (иман, тело и питание, разум, работа и деньги), отчёт в конце дня, деньги и фонд отдыха, книга месяца, календарь месяца в цветах (прогресс/регресс к прошлому месяцу), XP, уровни, монеты, магазин наград и главная награда месяца — отдых.

- `public/` — само приложение (один `index.html`, service worker, иконки).
- `netlify/functions/sync.mjs` — облачная синхронизация между устройствами по секретному коду.
- `netlify/functions/push.mjs` + `remind.mjs` — push-уведомления по расписанию (крон каждые 5 минут, часовой пояс устройства).

## Деплой на Netlify

Отдельный сайт с base directory `discipline`. Переменные окружения (scope: Functions): `VAPID_PUBLIC`, `VAPID_PRIVATE` (`npx web-push generate-vapid-keys`).
