# Рассылка Damillion

Сайт для холодной рассылки в WhatsApp. Работник открывает очередь клиентов, жмёт «Открыть чат» (текст уже вписан), статус ставится сам; через N часов без ответа клиент всплывает в «Дожать» со вторым текстом. Владелец видит сводку, команду (кто онлайн, сколько сегодня), отчёт по дням и выгружает Excel.

## Установка на Netlify

Import этого репозитория как проект (netlify.toml уже настроен). Переменные окружения (Site configuration → Environment variables):

- `OWNER_LOGIN`, `OWNER_PASS` — вход владельца
- `WORKER_LOGIN`, `WORKER_PASS` — общий вход работников (каждый вводит своё имя)
- `SEED_KEY` — ключ, которым расшифровывается стартовый список клиентов (`netlify/lib/seed-data.mjs`)

После смены переменных: Deploys → Trigger deploy.

## Где данные

Netlify Blobs этого сайта (Data & Storage → Blobs, store `rassylka`). В репозитории список клиентов лежит только в зашифрованном виде.
